# 2. Viewing the Interactive Presentation

## Local Execution

The presentation is designed to run locally in a modern web browser.

### No Development Environment Required

You do **not** need:

* Node.js
* npm
* a local development server
* browser extensions
* programming software

Simply open:

```text
index.html
```

in a supported browser.

### Recommended Browsers

For the best visual rendering, use a modern Chromium-based browser:

* **Google Chrome** — Recommended
* **Microsoft Edge** — Recommended
* **Brave Browser** — Supported

# 3. Presentation Controls

| Action                      | Keyboard / Mouse                 | Function                                                     |
| :-------------------------- | :------------------------------- | :----------------------------------------------------------- |
| **Next Slide**              | `→`, `Space`, `PageDown`, or `>` | Advances to the next slide                                   |
| **Previous Slide**          | `←`, `PageUp`, or `<`            | Returns to the previous slide                                |
| **First Slide**             | `Home`                           | Returns to Slide 1                                           |
| **Final Slide**             | `End`                            | Jumps to the final slide                                     |
| **Clean Presentation Mode** | `H`                              | Hides the interface controls for a cleaner presentation view |
| **Fullscreen**              | `F11`                            | Displays the presentation edge-to-edge                       |
| **Export PDF**              | `P` or the PDF button            | Opens the browser print dialog for PDF export                |

The presentation contains **7 slides**.

# 5. PDF Export

The presentation includes a print stylesheet designed for **A4 landscape PDF output**.

## Recommended Export Procedure

1. Open `index.html` using Google Chrome, Microsoft Edge, or Brave.
2. Select **Export PDF Deck** or press `P`.
3. In the browser print dialog, select:

```text
Destination:          Save as PDF
Layout:               Landscape
Paper Size:           A4
Margins:              None
Background Graphics:  Enabled
Headers & Footers:    Disabled
```

4. Select **Save**.

The resulting PDF should contain the complete 7-slide presentation in landscape format.

> **Note:** The HTML presentation is the interactive master version. The exported PDF provides a conventional, easily accessible version of the same presentation material.
